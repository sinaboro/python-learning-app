## 📱 학습 앱

- 교안과 **같은 원고**로 만든 앱이라 내용이 똑같아요.
- 검은 코드 상자를 **고쳐서 ▶ 실행**할 수 있어요. 브라우저 안에서 진짜 파이썬(Pyodide)이 돌아갑니다. `input()` 은 입력 창으로 받아요.
- 처음 실행할 때만 파이썬을 내려받고(약 10MB), 그다음에는 **인터넷 없이도** 실행돼요.
- 장마다 **총정리 퀴즈**(바로 채점·해설), 진도 기록, 자유롭게 코드를 쓰는 **실습장** 탭이 있어요.
- 무한 반복은 10초 뒤 자동으로 멈춰요.

### 설치 방법 (가장 쉬운 방법: 카카오톡)
1. 카카오톡으로 받은 링크 `https://sinaboro.github.io/python-learning-app/` 를 누릅니다.
2. 앱이 **자동으로 Chrome(아이폰은 Safari)으로 넘어갑니다.** 안 넘어가면 위쪽 안내의 **[Chrome으로 열기]** 를 누릅니다.
3. 화면 위쪽 **"홈 화면에 앱으로 설치하면…"** 안내의 **[설치]** → 확인 창에서 **설치**.
   - 안내가 안 보이면 Chrome **`⋮` → 앱 설치(홈 화면에 추가)**
   - 아이폰은 Safari **공유 버튼 → 홈 화면에 추가 → 추가**
4. 홈 화면에 **파이썬** 아이콘이 생깁니다. 설치 후 인터넷이 될 때 한 번 열고, 코드도 한 번 실행해 두면 비행기 모드에서도 공부할 수 있어요.

새 내용이 추가되면 인터넷이 될 때 앱을 열면 **자동으로 업데이트**됩니다. 진도 기록은 그대로 남아요.

## 🛠 내용을 고치거나 추가하려면

원고는 `guide/chNN.md` **한 곳**에만 있고, 교안 PDF·앱·실습코드는 모두 여기서 자동으로 만들어집니다.

```
pip install reportlab pillow
python tools/build_pdf.py          # 교안 PDF (예제를 실제로 실행해 결과를 넣음)
python tools/build_app.py --bump   # 앱 내용 docs/content.js + 앱 버전 올리기
python tools/build_code.py         # 실습코드 폴더
```

| 파일·폴더 | 설명 |
|---|---|
| `guide/ch01.md` ~ `ch13.md` | 원고 (13 = 부록). 문법은 `tools/guide_lib.py` 맨 위 설명 참고 |
| `tools/guide_lib.py` | 원고 읽기 + 예제 실행 (공통) |
| `tools/build_pdf.py` | 교안 PDF 만들기 (ReportLab, 맑은 고딕 + D2Coding) |
| `tools/build_app.py` | 앱 데이터 만들기 |
| `tools/build_code.py` | 실습코드 만들기 |
| `tools/make_icons.py` | 앱 아이콘 |
| `docs/` | 앱 (GitHub Pages로 배포). `index.html` 화면, `app.js` 기능, `content.js` 자동 생성 내용, `sw.js` 오프라인 |

- 원고 문법 예: `## 03.4 | 절 제목`, ` ```python input=17 ` (input() 에 넣을 값), ` ```python norun ` (실행하지 않는 예시), ` ```python file=calc.py ` (모듈 파일), `@quiz ? 질문 / - 오답 / + 정답 / = 해설 @end`
- 앱의 진도는 `"장/절번호"`로 저장되므로 절을 추가해도 기존 기록이 유지됩니다.
- 빌드할 때 `PYTHONHASHSEED=0` 을 주면 집합(set) 출력 순서가 항상 같아집니다.

# 03 | 기본 자료형

@goals
- 자료형이 무엇인지, type() 으로 확인하는 법을 안다.
- 정수·실수 계산과 연산자 우선순위를 이해한다.
- 문자열을 만들고 더하기·곱하기·길이 구하기를 할 수 있다.
- 자료형을 서로 바꿀 수 있다 (int, float, str).
- 인덱싱과 슬라이싱으로 문자열 일부를 꺼낼 수 있다.

## 03.1 | 자료형과 데이터

프로그램이 다루는 값(데이터)에는 **종류**가 있어요. 이것을 **자료형(type)**이라고 합니다. 숫자는 더할 수 있고, 글자는 붙일 수 있듯이 자료형에 따라 할 수 있는 일이 달라요. `type()` 으로 값의 자료형을 확인할 수 있습니다.

| 자료형 | 이름 | 예 |
|---|---|---|
| int | 정수 | 10, -3, 0 |
| float | 실수(소수) | 3.14, -0.5 |
| str | 문자열(글자) | "hello", '파이썬' |
| bool | 불리언(참·거짓) | True, False |

```python
print(type(10))
print(type(3.14))
print(type("안녕"))
print(type(True))
```

## 03.2 | 숫자

### 사칙연산과 여러 연산자

| 연산자 | 뜻 | 예 | 결과 |
|---|---|---|---|
| + | 더하기 | 7 + 2 | 9 |
| - | 빼기 | 7 - 2 | 5 |
| * | 곱하기 | 7 * 2 | 14 |
| / | 나누기 (항상 실수) | 7 / 2 | 3.5 |
| // | 몫 | 7 // 2 | 3 |
| % | 나머지 | 7 % 2 | 1 |
| ** | 거듭제곱 | 7 ** 2 | 49 |

```python
print(7 / 2, 7 // 2, 7 % 2)
print(2 ** 10)          # 2 를 10번 곱하기
print(10 / 5)           # 나누어떨어져도 / 의 결과는 실수
```

> 💡 `%` (나머지)는 짝수·홀수 판별에 자주 써요. `n % 2 == 0` 이면 짝수입니다.

### 연산 순서

수학처럼 `**` → `* / // %` → `+ -` 순서로 계산해요. 헷갈리면 **괄호**를 쓰세요.

```python
print(2 + 3 * 4)        # 곱하기 먼저 → 14
print((2 + 3) * 4)      # 괄호 먼저 → 20
```

### 실수 계산의 작은 오차

컴퓨터는 실수를 2진수로 저장해서 아주 작은 오차가 생길 수 있어요. 출력할 때 `round()` 로 반올림하면 됩니다.

```python
print(0.1 + 0.2)
print(round(0.1 + 0.2, 2))   # 소수점 둘째 자리까지 반올림
```

## 03.3 | 문자열

글자들의 줄을 **문자열**이라고 해요. 큰따옴표(" ")나 작은따옴표(' ')로 감쌉니다. 여러 줄은 따옴표 세 개(""" """)로 감싸요.

```python
a = "큰따옴표 문자열"
b = '작은따옴표 문자열'
c = """여러 줄을
그대로 쓸 수 있어요"""
print(a); print(b); print(c)
```

글자 안에 따옴표를 넣고 싶으면 다른 종류의 따옴표로 감싸거나, 앞에 `\` 를 붙여요.

```python
print("He said 'Hi'")
print('It\'s OK')
```

### 문자열 더하기·곱하기·길이

```python
first = "파이"
last = "썬"
print(first + last)        # 이어 붙이기
print("=" * 20)            # 20번 반복
print(len("Hello"))        # 글자 수
```

## 03.4 | 문자열 응용과 자료형 변환

### 숫자와 문자열은 바로 더할 수 없어요

```python
age = 20
print("나이: " + age)      # 문자열 + 정수 → 오류
```

`TypeError` 는 "자료형이 맞지 않는다"는 뜻이에요. **자료형 변환** 함수로 맞춰 줍니다.

| 함수 | 바꾸는 자료형 | 예 | 결과 |
|---|---|---|---|
| int() | 정수 | int("25"), int(3.9) | 25, 3 (버림) |
| float() | 실수 | float("2.5") | 2.5 |
| str() | 문자열 | str(100) | "100" |

```python
age = 20
print("나이: " + str(age))   # 숫자를 문자열로
year = "2026"
print(int(year) + 1)         # 문자열을 숫자로
print(int(3.9))              # 실수 → 정수는 소수점 아래를 버린다
```

> 💡 `input()` 으로 받은 값은 **항상 문자열**이에요. 숫자로 계산하려면 `int(input())` 처럼 바꿔야 합니다. (9장에서 자세히 배워요)

```python input=17
n = input("숫자를 입력하세요: ")
print("두 배:", int(n) * 2)
```

## 03.5 | 문자열 인덱싱과 슬라이싱

문자열의 글자에는 **번호(인덱스)**가 있어요. 맨 앞이 **0번**이고, 뒤에서부터는 **-1, -2 …** 로 셀 수 있습니다.

| 글자 | P | y | t | h | o | n |
|---|---|---|---|---|---|---|
| 앞에서 | 0 | 1 | 2 | 3 | 4 | 5 |
| 뒤에서 | -6 | -5 | -4 | -3 | -2 | -1 |

```python
s = "Python"
print(s[0])      # 첫 글자
print(s[-1])     # 마지막 글자
print(s[2])
```

### 슬라이싱: [시작:끝] — 끝 번호는 포함하지 않아요

```python
s = "Python"
print(s[0:2])    # 0, 1 번 → Py
print(s[2:])     # 2번부터 끝까지
print(s[:4])     # 처음부터 3번까지
print(s[::-1])   # 거꾸로 (간격 -1)
```

```python
date = "20261104"
print(date[:4] + "년", date[4:6] + "월", date[6:] + "일")
```

!> 문자열은 **바꿀 수 없는(immutable)** 자료형이에요. `s[0] = "J"` 처럼 글자 하나를 바꾸면 오류가 나요. 새 문자열을 만들어야 합니다.

## 03.6 | 문자열 다양하게 다뤄보기

문자열 뒤에 `.` 을 찍고 쓰는 기능을 **메서드**라고 해요. 원래 문자열은 그대로 두고 **새 문자열을 돌려줍니다.**

| 메서드 | 하는 일 | 예 | 결과 |
|---|---|---|---|
| upper() / lower() | 대문자 / 소문자로 | "Hi".upper() | "HI" |
| strip() | 양쪽 공백 지우기 | "  hi ".strip() | "hi" |
| replace(a, b) | a 를 b 로 바꾸기 | "a-b".replace("-", "+") | "a+b" |
| split(구분자) | 나눠서 리스트로 | "a,b".split(",") | ['a', 'b'] |
| join(리스트) | 이어 붙이기 | "-".join(['a','b']) | "a-b" |
| find(글자) | 위치 찾기 (없으면 -1) | "hello".find("l") | 2 |
| count(글자) | 개수 세기 | "banana".count("a") | 3 |
| startswith() | ~로 시작하나 | "file.py".startswith("file") | True |

```python
text = "  Hello Python  "
print(text.strip())
print(text.strip().upper())
print("사과,배,포도".split(","))
print(" / ".join(["월", "화", "수"]))
print("banana".count("a"), "banana".find("n"))
print("I like Java".replace("Java", "Python"))
```

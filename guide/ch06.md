## 06.1 | while 문과 반복문의 기초

같은 일을 여러 번 해야 할 때 코드를 복사해 붙이면 길고 고치기 어려워요. **반복문**을 쓰면 한 번만 쓰고 여러 번 실행할 수 있어요. **while 문**은 **조건이 참인 동안** 계속 반복합니다.

```python
count = 1
while count <= 5:            # count 가 5 이하인 동안
    print(f"{count}번째 인사: 안녕!")
    count += 1               # 이 줄이 없으면 영원히 반복된다
print("반복 끝")
```

!> 조건이 계속 참이면 **무한 반복**에 빠져요. 실행 중인 프로그램은 **Ctrl + C** 로 멈출 수 있어요. 반복할 때마다 조건이 바뀌는지 꼭 확인하세요.

### break: 반복 멈추기, continue: 이번만 건너뛰기

```python
n = 0
while True:                  # 일부러 무한 반복을 만들고
    n += 1
    if n % 2 == 0:
        continue             # 짝수면 아래를 건너뛰고 다시 처음으로
    if n > 9:
        break                # 9 를 넘으면 반복 탈출
    print(n, end=" ")
```

```python input=3|7|0
# 0 을 입력할 때까지 숫자를 더하는 계산기
total = 0
while True:
    num = int(input("숫자 (0=끝): "))
    if num == 0:
        break
    total += num
print("합계:", total)
```

## 06.2 | for 문과 순회

**for 문**은 여러 값이 담긴 것에서 **하나씩 꺼내며** 반복해요. 하나씩 차례로 꺼내는 것을 **순회**라고 합니다.

```python
for ch in "파이썬":
    print(ch)
```

### range(): 숫자 줄 만들기

| 쓰는 법 | 만들어지는 숫자 |
|---|---|
| range(5) | 0, 1, 2, 3, 4 |
| range(1, 6) | 1, 2, 3, 4, 5 (끝은 포함 안 함) |
| range(0, 10, 2) | 0, 2, 4, 6, 8 (2씩 건너뛰기) |
| range(5, 0, -1) | 5, 4, 3, 2, 1 (거꾸로) |

```python
for i in range(1, 6):
    print(i, end=" ")
print()
total = 0
for i in range(1, 101):
    total += i
print("1부터 100까지의 합:", total)
```

> 💡 횟수가 정해져 있으면 **for**, 언제 끝날지 모르고 조건으로 멈추면 **while** 을 쓰는 게 자연스러워요.

## 06.3 | 리스트와 반복문

```python
scores = [88, 72, 95, 60]
total = 0
for s in scores:
    total += s
print("평균:", total / len(scores))
```

### enumerate(): 번호와 값 함께, zip(): 두 리스트 나란히

```python
names = ["김파이", "이코딩", "박자바"]
for i, name in enumerate(names, start=1):
    print(f"{i}번: {name}")
scores = [90, 85, 77]
for name, score in zip(names, scores):
    print(name, score)
```

### 조건에 맞는 값만 모으기

```python
scores = [88, 72, 95, 60]
passed = []
for s in scores:
    if s >= 80:
        passed.append(s)
print(passed)
```

### 리스트 컴프리헨션: 한 줄로 리스트 만들기

위 코드를 한 줄로 쓸 수 있어요. `[식 for 변수 in 반복할것 if 조건]` 형태입니다.

```python
scores = [88, 72, 95, 60]
passed = [s for s in scores if s >= 80]
squares = [n ** 2 for n in range(1, 6)]
print(passed, squares)
```

### 딕셔너리 돌기

```python
prices = {"커피": 4500, "라떼": 5000, "케이크": 6500}
for menu, price in prices.items():
    print(f"{menu}: {price:,}원")      # :, → 천 단위 쉼표
```

## 06.4 | 중첩 반복문

반복문 안에 반복문을 넣을 수 있어요. 바깥 반복이 한 번 돌 때 안쪽 반복은 처음부터 끝까지 다 돕니다.

```python
for dan in range(2, 4):            # 2단, 3단
    for i in range(1, 10):         # 1 ~ 9
        print(f"{dan}×{i}={dan * i:2}", end="  ")
    print()                        # 한 단이 끝나면 줄바꿈
```

```python
# 별로 삼각형 그리기
for row in range(1, 6):
    print("*" * row)
```

```python
# 2차원 리스트(표) 돌기
table = [[1, 2, 3], [4, 5, 6]]
for row in table:
    for value in row:
        print(value, end=" ")
    print()
```

## 05.1 | if 문

"비가 오면 우산을 챙긴다"처럼 **조건에 따라 할 일을 바꾸는 것**을 조건문이라고 해요.

```python
temperature = 31
if temperature >= 30:
    print("너무 더워요!")       # 조건이 참일 때만 실행
    print("물을 많이 마셔요.")
print("오늘도 좋은 하루")         # if 와 상관없이 항상 실행
```

### 들여쓰기가 곧 문법

조건이 참일 때 실행할 코드는 **들여쓰기(보통 공백 4칸)**로 묶어요. 다른 언어의 중괄호 `{ }` 역할을 파이썬은 들여쓰기가 합니다. if 줄 끝의 **콜론(:)**도 잊지 마세요.

```python
if True:
print("들여쓰기를 안 하면?")
```

### else 와 elif

```python
score = 85
if score >= 90:
    grade = "A"
elif score >= 80:          # 위 조건이 거짓일 때 다음 조건 검사
    grade = "B"
elif score >= 70:
    grade = "C"
else:                      # 모든 조건이 거짓일 때
    grade = "F"
print(f"{score}점은 {grade}학점")
```

> 💡 elif 는 **위에서부터 차례로** 검사하고, 처음 참이 된 곳 하나만 실행해요. 그래서 조건의 순서가 중요합니다. (85점은 `>= 80` 에서 멈춰요)

### 짧은 조건식 (삼항 연산자)

```python
age = 15
label = "성인" if age >= 19 else "청소년"
print(label)
```

## 05.2 | 비교 연산자, 논리 연산자

### 비교 연산자 — 결과는 True 또는 False

| 연산자 | 뜻 | 예 (a=5, b=3) |
|---|---|---|
| == | 같다 | a == b → False |
| != | 다르다 | a != b → True |
| > , < | 크다, 작다 | a > b → True |
| >= , <= | 크거나 같다, 작거나 같다 | a <= 5 → True |

!> `=` 는 값을 넣는 대입, `==` 는 같은지 비교예요. if 에는 `==` 를 씁니다.

### 논리 연산자 — 조건 여러 개 합치기

| 연산자 | 뜻 | 예 |
|---|---|---|
| and | 둘 다 참이면 참 | age >= 13 and age <= 18 |
| or | 하나라도 참이면 참 | day == "토" or day == "일" |
| not | 참·거짓 뒤집기 | not is_member |

```python
age = 16
has_ticket = True
if age >= 13 and has_ticket:
    print("입장 가능")
day = "일"
if day == "토" or day == "일":
    print("주말이에요")
print(not has_ticket)
```

```python
# 파이썬은 범위를 수학처럼 쓸 수 있다
n = 7
if 1 <= n <= 10:
    print("1부터 10 사이")
print(n % 2 == 0)          # 짝수인가?
```

### in 으로 포함 여부 검사

```python
vip = ["김파이", "이코딩"]
name = "김파이"
if name in vip:
    print(f"{name}님, VIP 라운지로 오세요")
```

## 05.3 | try~except 문

프로그램을 실행하다 오류가 나면 그 자리에서 멈춰 버려요. **try~except** 를 쓰면 오류가 나도 멈추지 않고 대신 할 일을 정할 수 있어요.

```python
try:
    result = 10 / 0          # 0 으로 나누면 오류가 난다
    print(result)
except ZeroDivisionError:
    print("0 으로는 나눌 수 없어요.")
print("프로그램은 계속 실행돼요")
```

사용자가 숫자 대신 글자를 입력하는 경우도 자주 막아야 해요.

```python input=스물
text = input("나이를 숫자로 입력하세요: ")
try:
    age = int(text)
    print(f"내년에는 {age + 1}살")
except ValueError:
    print("숫자만 입력해 주세요.")
```

> 💡 어떤 오류가 날지 알면 `except ValueError:` 처럼 오류 이름을 적는 게 좋아요. 오류 처리는 10장에서 더 깊게 배웁니다.

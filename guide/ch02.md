## 02.1 | 변수

**변수**는 값을 담아 두는 **이름표 붙은 상자**예요. `=` 기호로 상자에 값을 넣습니다. 수학의 "같다"가 아니라 **"오른쪽 값을 왼쪽 이름에 넣어라"**는 뜻이에요.

```python
age = 20             # age 라는 상자에 20 을 넣는다
name = "김파이"       # 글자(문자열)도 담을 수 있다
print(name, age)
```

변수에는 언제든 새 값을 넣을 수 있어요. 그러면 예전 값은 사라지고 새 값으로 바뀝니다.

```python
score = 70
print("처음 점수:", score)
score = 95           # 새 값으로 바꾸기
print("바뀐 점수:", score)
```

> 💡 값을 넣지 않은 변수를 쓰면 `NameError` 가 나요. 변수는 **먼저 만들고 나중에 사용**해야 합니다.

## 02.2 | 변수 활용하기

변수끼리 계산하고, 계산 결과를 다시 변수에 담을 수 있어요.

```python
price = 4500         # 커피 한 잔 가격
count = 3            # 몇 잔
total = price * count
print("총 금액:", total, "원")
```

### 자기 자신을 이용해 값 바꾸기

`x = x + 1` 은 "x 에 1 을 더한 값을 다시 x 에 넣어라"예요. 줄여서 `x += 1` 로 쓸 수 있어요.

```python
step = 0
step = step + 1      # 1
step += 1            # 2 (위와 같은 뜻을 짧게)
step *= 10           # 20 (step = step * 10)
print(step)
```

### 여러 변수에 한 번에 넣기, 값 바꾸기

```python
a, b = 1, 2          # a 에 1, b 에 2
print("바꾸기 전:", a, b)
a, b = b, a          # 파이썬은 한 줄로 두 값을 바꿀 수 있다
print("바꾼 뒤:", a, b)
```

## 02.3 | 꼭 알아두면 좋은 프로그래밍 용어 12가지

앞으로 계속 나올 말들이에요. 지금은 "이런 말이 있구나" 정도로 훑어보고, 모르면 다시 돌아와 찾아보세요.

| 용어 | 뜻 | 예 |
|---|---|---|
| 코드 | 프로그래밍 언어로 쓴 글 | print("hi") |
| 실행 | 코드를 컴퓨터가 처리하는 것 | ▷ 버튼 |
| 변수 | 값을 담는 이름표 붙은 상자 | age = 20 |
| 값 | 변수에 담기는 데이터 | 20, "hi" |
| 자료형 | 값의 종류 | 정수, 문자열 |
| 연산자 | 계산·비교에 쓰는 기호 | + - * / == |
| 식(표현식) | 계산되어 값이 되는 코드 | 3 + 4 |
| 문(문장) | 실행되는 명령 한 줄 | x = 3 |
| 함수 | 이름으로 불러 쓰는 기능 묶음 | print(), len() |
| 인수 | 함수에 넘겨주는 값 | print("hi") 의 "hi" |
| 반환값 | 함수가 돌려주는 결과 | len("abc") → 3 |
| 오류(에러) | 실행이 멈추는 문제 | NameError |

```python
# 용어를 코드에서 찾아보기
word = "python"          # 문: word 라는 변수에 값 "python" 을 넣는다
length = len(word)       # 함수 len 에 인수 word 를 넘기고, 반환값 6 을 받는다
print(length * 2)        # 식 length * 2 가 계산되어 12 가 된다
```

## 02.4 | 변수·함수·클래스 이름 짓기

### 꼭 지켜야 하는 규칙 (안 지키면 오류)

- 영문자, 숫자, 밑줄(_)만 쓸 수 있어요. (한글도 되지만 권장하지 않아요)
- **숫자로 시작할 수 없어요.** `1st` (X), `first` (O)
- 띄어쓰기를 할 수 없어요. `my name` (X), `my_name` (O)
- `if`, `for`, `class` 같은 **예약어**는 이름으로 쓸 수 없어요.

```python norun
1st_place = "금메달"   # 숫자로 시작 → SyntaxError
for = 3               # 예약어 → SyntaxError
```

### 지키면 좋은 약속 (파이썬 스타일, PEP 8)

| 대상 | 방식 | 예 |
|---|---|---|
| 변수·함수 | 소문자 + 밑줄 (snake_case) | user_name, get_total |
| 클래스 | 단어 첫 글자 대문자 (PascalCase) | BankAccount |
| 상수 | 모두 대문자 | MAX_SIZE |

```python
MAX_SCORE = 100                 # 바뀌지 않을 값은 대문자로
student_name = "이코딩"          # 무엇이 담겼는지 알 수 있는 이름
math_score = 88
print(student_name, "의 수학 점수는", math_score, "/", MAX_SCORE)
```

> 💡 `a`, `x2`, `temp` 보다 `price`, `user_count` 처럼 **뜻이 드러나는 이름**이 좋아요. 이름만 봐도 무엇이 담겼는지 알 수 있어야 합니다.

## 02.5 | 다양한 출력 연습하기

### 쉼표로 여러 값 출력하기

`print()` 에 쉼표로 여러 값을 넣으면 **띄어쓰기 한 칸**으로 이어서 출력해요.

```python
print("사과", 3, "개")
```

### sep: 사이에 넣을 글자, end: 끝에 붙일 글자

```python
print("2026", "11", "04", sep="-")    # 사이를 - 로
print("한 줄에", end=" ")              # 줄을 바꾸지 않고 띄어쓰기만
print("이어서 출력")
```

### f-문자열: 글자 안에 변수 넣기

따옴표 앞에 `f` 를 붙이고 `{변수}` 를 쓰면 그 자리에 값이 들어가요. 가장 많이 쓰는 방법입니다.

```python
name = "김파이"
age = 20
print(f"제 이름은 {name}이고, 나이는 {age}살입니다.")
print(f"내년에는 {age + 1}살이 돼요.")        # 중괄호 안에서 계산도 된다
print(f"원주율은 약 {3.14159:.2f}입니다.")    # :.2f → 소수점 둘째 자리까지
```

### 특수 문자: \n 줄바꿈, \t 탭

```python
print("첫째 줄\n둘째 줄")
print("이름\t점수")
print("김파이\t95")
```

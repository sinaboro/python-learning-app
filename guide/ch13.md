## A | 인공지능과 함께 파이썬 공부하기

ChatGPT, Claude, Gemini 같은 AI 도구는 **24시간 옆에 있는 과외 선생님**처럼 쓸 수 있어요. 다만 답을 받아 적기만 하면 실력이 늘지 않아요. **스스로 생각한 다음에 묻는 것**이 핵심입니다.

### 이렇게 물어보면 좋아요

| 상황 | 질문 예시 |
|---|---|
| 개념이 어려울 때 | "파이썬의 딕셔너리를 중학생도 알 수 있게 비유로 설명해 줘" |
| 오류가 났을 때 | "이 코드에서 아래 오류가 났어. 원인과 고치는 방법을 알려 줘. (코드 + 오류 메시지 전체)" |
| 코드를 이해하고 싶을 때 | "이 코드를 한 줄씩 설명해 줘" |
| 연습 문제가 필요할 때 | "for 문 연습 문제 3개를 쉬운 것부터 내 줘. 정답은 내가 풀고 나서 알려 줘" |
| 내 코드를 점검받을 때 | "내가 짠 코드야. 더 읽기 쉽게 고칠 점을 알려 줘. 고친 이유도 설명해 줘" |

### 좋은 질문의 3요소

1. **상황**: 무엇을 하려고 했는지 ("성적 평균을 구하려고 했어")
2. **자료**: 코드와 오류 메시지 **전체**를 그대로 붙여 넣기
3. **원하는 것**: 정답 코드인지, 힌트인지, 설명인지 분명히

```text
나는 파이썬 초보야. 리스트의 평균을 구하려고 아래처럼 썼는데 오류가 나.
정답 코드보다는 어디가 틀렸는지 힌트를 먼저 줘.

scores = ["90", "80"]
print(sum(scores) / len(scores))

TypeError: unsupported operand type(s) for +: 'int' and 'str'
```

!> AI 도 **틀린 답을 그럴듯하게** 말할 수 있어요. 받은 코드는 반드시 직접 실행해 확인하고, 이해하지 못한 코드는 쓰지 마세요. 개인정보·비밀번호·API 키는 절대 붙여 넣지 마세요.

> 💡 추천 공부법: ① 교안을 읽고 ② 예제를 직접 쳐서 실행하고 ③ 숫자를 바꿔 결과를 예상해 보고 ④ 막히면 AI 에게 힌트를 요청하고 ⑤ 퀴즈로 확인하기.

## B | 자주 쓰는 내장 함수 25가지

내장 함수는 import 없이 바로 쓸 수 있는 함수예요.

| 함수 | 하는 일 | 예 → 결과 |
|---|---|---|
| print() | 화면에 출력 | print("hi") → hi |
| input() | 키보드 입력 (문자열) | input("이름: ") |
| len() | 길이·개수 | len("abc") → 3 |
| type() | 자료형 확인 | type(3) → int |
| int() | 정수로 변환 | int("7") → 7 |
| float() | 실수로 변환 | float("1.5") → 1.5 |
| str() | 문자열로 변환 | str(10) → "10" |
| list() | 리스트로 변환 | list("ab") → ['a', 'b'] |
| tuple() | 튜플로 변환 | tuple([1, 2]) → (1, 2) |
| dict() | 딕셔너리 만들기 | dict(a=1) → {'a': 1} |
| set() | 집합으로 변환 | set([1, 1, 2]) → {1, 2} |
| range() | 숫자 줄 | list(range(3)) → [0, 1, 2] |
| sum() | 합계 | sum([1, 2, 3]) → 6 |
| max() | 최댓값 | max(3, 7) → 7 |
| min() | 최솟값 | min([4, 2]) → 2 |
| abs() | 절댓값 | abs(-5) → 5 |
| round() | 반올림 | round(3.567, 1) → 3.6 |
| sorted() | 정렬된 새 리스트 | sorted([3, 1]) → [1, 3] |
| reversed() | 거꾸로 꺼내기 | list(reversed([1, 2])) → [2, 1] |
| enumerate() | 번호와 함께 | list(enumerate("ab")) → [(0, 'a'), (1, 'b')] |
| zip() | 나란히 묶기 | list(zip([1, 2], "ab")) → [(1, 'a'), (2, 'b')] |
| map() | 모두에 함수 적용 | list(map(int, ["1", "2"])) → [1, 2] |
| filter() | 조건에 맞는 것만 | list(filter(None, [0, 1, 2])) → [1, 2] |
| any() / all() | 하나라도 참 / 모두 참 | any([0, 1]) → True |
| isinstance() | 자료형 검사 | isinstance(3, int) → True |

```python
words = ["banana", "Apple", "cherry"]
print(sorted(words, key=str.lower))              # 대소문자 무시하고 정렬
print(list(map(len, words)))
print(any(w.startswith("A") for w in words), all(len(w) > 3 for w in words))
print(divmod(17, 5), pow(2, 5), chr(65), ord("A"))   # 덤: 몫과 나머지, 거듭제곱, 문자↔코드
```

## C | 자주 쓰는 표준 라이브러리 12가지

| 모듈 | 하는 일 | 대표 기능 |
|---|---|---|
| math | 수학 계산 | sqrt, ceil, floor, pi |
| random | 난수 | randint, choice, shuffle, sample |
| datetime | 날짜·시간 | date, datetime.now(), timedelta |
| time | 시간 재기·기다리기 | time(), sleep() |
| os | 파일·폴더 다루기 | listdir, path.exists, makedirs |
| sys | 파이썬 실행 환경 | argv, exit, version |
| json | JSON 변환 | dumps, loads, dump, load |
| csv | CSV 파일 읽기·쓰기 | reader, writer, DictReader |
| re | 정규 표현식(패턴 찾기) | findall, sub, match |
| collections | 편리한 자료형 | Counter, defaultdict, deque |
| statistics | 통계 | mean, median, stdev |
| pathlib | 경로를 객체로 다루기 | Path, read_text, glob |

```python
import math, statistics, re
from collections import Counter
from datetime import date, timedelta

print(math.sqrt(2) ** 2 == 2, math.isclose(math.sqrt(2) ** 2, 2))   # 실수 비교는 isclose
print(statistics.mean([70, 80, 95]), statistics.median([3, 1, 2]))
print(Counter("hello world").most_common(2))                       # 가장 많이 나온 글자
print(re.findall(r"\d+", "주문 3개, 가격 4500원"))                  # 숫자만 뽑기
print(date(2026, 11, 4) + timedelta(days=100))                      # 100일 뒤
```

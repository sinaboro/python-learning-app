## 11.1 | 모듈은 왜 필요할까?

프로그램이 커지면 파일 하나에 모든 코드를 넣기 어려워요. 기능별로 **파일을 나눠 두고 필요할 때 가져다 쓰면** 정리가 잘 되고, 다른 프로그램에서도 재사용할 수 있어요. 이렇게 가져다 쓸 수 있는 파이썬 파일(.py)을 **모듈**이라고 합니다.

| 용어 | 뜻 | 예 |
|---|---|---|
| 모듈 | 가져다 쓰는 .py 파일 하나 | math, random, 내가 만든 calc.py |
| 패키지 | 모듈을 모은 폴더 | json, urllib |
| 라이브러리 | 모듈·패키지 모음을 넓게 부르는 말 | 표준 라이브러리, pandas |
| 표준 라이브러리 | 파이썬을 설치하면 함께 오는 것 | math, random, datetime |
| 외부 라이브러리 | pip 로 따로 설치하는 것 | requests, pandas |

```python
import math                        # math 모듈 가져오기
print(math.sqrt(16))               # 모듈이름.기능 으로 사용
print(math.pi)
```

## 11.2 | 표준 라이브러리 활용하기

### import 하는 여러 방법

```python
import random                      # ① 모듈 전체
from math import ceil, floor       # ② 필요한 기능만 → 이름만으로 사용
import datetime as dt              # ③ 별명 붙이기

print(random.randint(1, 6))        # 1~6 주사위 (실행할 때마다 다름)
print(ceil(3.2), floor(3.8))       # 올림, 내림
print(dt.date(2026, 12, 25) - dt.date(2026, 11, 4))   # 날짜 빼기
```

### 자주 쓰는 표준 라이브러리 맛보기

```python
import random
menu = ["김밥", "라면", "돈가스", "비빔밥"]
print("오늘 점심:", random.choice(menu))     # 하나 고르기
cards = [1, 2, 3, 4, 5]
random.shuffle(cards)                        # 섞기
print(cards, random.sample(range(1, 46), 6)) # 겹치지 않게 6개 뽑기
```

## 11.3 | 모듈 만들고 사용해보기

함수를 담은 .py 파일을 만들면 그게 바로 모듈이에요. 같은 폴더에 아래 `calc.py` 를 저장해 보세요.

```python file=calc.py
# calc.py — 계산 기능을 모아 둔 나만의 모듈
PI = 3.14159

def add(a, b):
    return a + b

def circle_area(r):
    return PI * r ** 2

if __name__ == "__main__":        # 이 파일을 직접 실행할 때만 아래가 실행된다
    print("calc.py 시험 실행:", add(1, 2))
```

같은 폴더의 다른 파일(예: main.py)에서 가져다 씁니다.

```python
import calc                       # calc.py 를 가져온다 (.py 는 쓰지 않음)
print(calc.add(10, 5))
print(round(calc.circle_area(3), 2))
from calc import PI
print(PI)
```

### if __name__ == "__main__": 의 뜻

| 실행 방법 | __name__ 의 값 | 아래 코드 |
|---|---|---|
| python calc.py (직접 실행) | "__main__" | 실행됨 |
| import calc (가져다 씀) | "calc" | 실행 안 됨 |

모듈 안에 시험용 코드를 넣어 두어도, 다른 파일에서 import 할 때는 실행되지 않게 막아 주는 장치예요.

## 11.4 | 패키지와 외부 라이브러리 알아보기

### pip 로 외부 라이브러리 설치하기

전 세계 개발자가 만든 라이브러리는 **PyPI**(pypi.org)에 모여 있고, 명령 프롬프트에서 `pip` 로 설치해요.

```text
C:\> pip install requests        ← 설치
C:\> pip list                    ← 설치된 목록
C:\> pip uninstall requests      ← 삭제
```

| 라이브러리 | 하는 일 |
|---|---|
| requests | 웹 페이지·API 가져오기 |
| pandas | 표 데이터 분석 |
| matplotlib | 그래프 그리기 |
| numpy | 빠른 숫자 계산 |
| flask / fastapi | 웹 서버 만들기 |


## 11.5 | 메모장 프로그램을 모듈로 나누기

10장의 메모장을 **파일 저장 담당 모듈**과 **화면 담당 프로그램**으로 나눠 봐요. 역할이 나뉘면 고치기도, 다른 곳에서 다시 쓰기도 쉬워져요.

```python file=memo_store.py
# memo_store.py — 메모를 파일에 읽고 쓰는 일만 담당하는 모듈
FILE = "memo_mod.txt"

def load():
    """저장된 메모 목록을 돌려준다. 파일이 없으면 빈 리스트."""
    try:
        with open(FILE, encoding="utf-8") as f:
            return [line.strip() for line in f if line.strip()]
    except FileNotFoundError:
        return []

def add(text):
    with open(FILE, "a", encoding="utf-8") as f:
        f.write(text + "\n")

def clear():
    open(FILE, "w", encoding="utf-8").close()
```

```python input=1|모듈 공부|1|패키지 공부|2|3
# memo_app.py — 화면(입력·출력)만 담당, 저장은 memo_store 에게 맡긴다
import memo_store as store
store.clear()                                  # 실습을 위해 비우고 시작

while True:
    menu = input("[1]쓰기 [2]목록 [3]끝 > ")
    if menu == "1":
        store.add(input("메모: "))
    elif menu == "2":
        for i, m in enumerate(store.load(), 1):
            print(f"  {i}. {m}")
    elif menu == "3":
        break
```

## 11.6 | 모듈과 라이브러리 연습하기

표준 라이브러리 여러 개를 함께 써서 **로또 번호 생성기**와 **D-day 계산기**를 만들어 봐요.

```python
import random
from datetime import date

def lotto():
    return sorted(random.sample(range(1, 46), 6))   # 1~45 중 겹치지 않게 6개

def d_day(target):
    left = (target - date(2026, 11, 4)).days        # 오늘을 2026-11-04 로 가정
    return f"D-{left}" if left > 0 else ("D-Day" if left == 0 else f"D+{-left}")

for i in range(1, 4):
    print(f"{i}게임: {lotto()}")
print("크리스마스까지", d_day(date(2026, 12, 25)))
```

## 07.1 | 함수의 개념 알아보기

**함수**는 자주 쓰는 코드를 **이름 붙여 묶어 둔 것**이에요. 한 번 만들어 두면 이름만 불러서(호출) 몇 번이고 쓸 수 있어요. `print()`, `len()` 도 파이썬이 미리 만들어 둔 함수입니다.

```python
def say_hello():            # def 함수이름(): 으로 정의
    print("안녕하세요!")
    print("파이썬 함수 시간입니다.")

say_hello()                 # 호출: 이름 뒤에 () 를 붙인다
say_hello()
```

> 💡 함수를 쓰면 ① 같은 코드를 반복해서 쓰지 않아도 되고 ② 고칠 때 한 곳만 고치면 되고 ③ 이름만 봐도 무슨 일을 하는지 알 수 있어요.

### 매개변수: 함수에 값 넘겨주기

```python
def greet(name):            # name 은 매개변수 (값을 받는 자리)
    print(f"{name}님, 반가워요!")

greet("김파이")              # "김파이" 는 인수 (넘겨주는 값)
greet("이코딩")
```

## 07.2 | 함수와 반환 알아보기

`return` 은 함수의 계산 결과를 **호출한 곳으로 돌려줘요.** 돌려받은 값은 변수에 담거나 다른 계산에 쓸 수 있습니다.

```python
def add(a, b):
    return a + b            # 결과를 돌려주고 함수를 끝낸다

result = add(3, 4)
print(result)
print(add(10, 20) * 2)      # 반환값을 바로 계산에 쓰기
```

### print 와 return 은 달라요

```python
def show_double(x):
    print(x * 2)            # 화면에 보여 주기만 한다

def get_double(x):
    return x * 2            # 값을 돌려준다

a = show_double(5)          # 10 이 출력되지만
b = get_double(5)
print("a =", a)             # a 에는 아무 값도 없다 (None)
print("b =", b)
```

### 값을 여러 개 돌려주기

```python
def min_max(numbers):
    return min(numbers), max(numbers)     # 튜플로 돌려준다

low, high = min_max([7, 2, 9, 4])
print(f"최솟값 {low}, 최댓값 {high}")
```

> 💡 return 을 만나면 함수는 **그 자리에서 끝나요.** 그 아래 코드는 실행되지 않습니다.

## 07.3 | 매개변수 좀 더 깊게 알아보기

### 기본값과 키워드 인수

```python
def order(menu, size="보통", count=1):    # 기본값이 있는 매개변수는 뒤에
    print(f"{menu} {size} {count}개 주문")

order("라면")                              # 기본값 사용
order("짜장면", "곱빼기")
order("커피", count=3)                     # 이름=값 으로 원하는 것만 지정
```

### 가변 인수: *args (개수 제한 없이), **kwargs (이름=값 여러 개)

```python
def total(*nums):           # 넘긴 값들이 튜플로 모인다
    return sum(nums)

print(total(1, 2), total(1, 2, 3, 4, 5))

def profile(**info):        # 이름=값 들이 딕셔너리로 모인다
    for key, value in info.items():
        print(f"{key}: {value}")

profile(name="김파이", age=20, city="서울")
```

!> 기본값으로 리스트 같은 바뀌는 값을 쓰면(`def f(a=[])`) 호출할 때마다 같은 리스트가 공유되는 함정이 있어요. 기본값은 `None` 으로 두고 함수 안에서 새로 만드세요.

## 07.4 | 함수를 한 줄로 정의할 수 있는 람다

`lambda 매개변수: 식` 은 이름 없는 짧은 함수예요. 주로 다른 함수에 **잠깐 넘겨줄 때** 씁니다.

```python
square = lambda x: x ** 2
print(square(5))

students = [("김파이", 85), ("이코딩", 92), ("박자바", 78)]
students.sort(key=lambda s: s[1], reverse=True)    # 점수(1번 값)로 정렬
print(students)
```

```python
nums = [1, 2, 3, 4, 5, 6]
print(list(map(lambda n: n * 10, nums)))        # 모두에 적용
print(list(filter(lambda n: n % 2 == 0, nums))) # 조건에 맞는 것만
```

## 07.5 | 함수와 스코프

변수가 **쓰일 수 있는 범위**를 스코프라고 해요.

- **지역 변수**: 함수 안에서 만든 변수. 함수가 끝나면 사라지고, 밖에서는 보이지 않아요.
- **전역 변수**: 함수 밖에서 만든 변수. 어디서든 읽을 수 있어요.

```python
message = "전역"             # 전역 변수

def func():
    message = "지역"         # 같은 이름이지만 함수 안의 새 변수
    print("함수 안:", message)

func()
print("함수 밖:", message)   # 전역 변수는 그대로
```

```python
def make_number():
    secret = 42
make_number()
print(secret)                # 지역 변수는 밖에서 쓸 수 없다
```

### global 로 전역 변수 바꾸기

```python
count = 0
def increase():
    global count             # 전역 변수 count 를 쓰겠다는 선언
    count += 1
increase(); increase()
print(count)
```

> 💡 `global` 은 꼭 필요할 때만 쓰세요. 함수는 **매개변수로 받고 return 으로 돌려주는 것**이 가장 깔끔합니다.

## 07.6 | 재귀 함수 알아보기

**재귀 함수**는 자기 자신을 다시 부르는 함수예요. 큰 문제를 같은 모양의 작은 문제로 나눠 풀 때 씁니다. 반드시 **멈추는 조건(종료 조건)**이 있어야 해요.

```python
def countdown(n):
    if n == 0:               # 종료 조건
        print("발사!")
        return
    print(n)
    countdown(n - 1)         # 더 작은 문제로 자기 자신 호출

countdown(3)
```

```python
def factorial(n):            # n! = n × (n-1)!
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))          # 5 × 4 × 3 × 2 × 1
```

!> 종료 조건이 없으면 끝없이 자신을 불러 `RecursionError` 가 나요. 파이썬은 기본적으로 약 1000번까지만 재귀를 허용합니다.

## 07.7 | 알아두면 좋은 파이썬 내장 함수 6가지

| 함수 | 하는 일 | 예 | 결과 |
|---|---|---|---|
| abs(x) | 절댓값 | abs(-7) | 7 |
| round(x, n) | 반올림 | round(3.146, 2) | 3.15 |
| sum(목록) | 합계 | sum([1, 2, 3]) | 6 |
| max / min | 최댓값 / 최솟값 | max(3, 9, 4) | 9 |
| sorted(목록) | 정렬된 새 리스트 | sorted([3, 1, 2]) | [1, 2, 3] |
| enumerate / zip | 번호 붙이기 / 나란히 묶기 | list(zip("ab", [1, 2])) | [('a', 1), ('b', 2)] |

```python
data = [-3, 8, 1, -9, 5]
print(abs(-3), round(2.675, 1), sum(data))
print(max(data), min(data), max(data, key=abs))   # key: 기준을 정할 수 있다
print(sorted(data, reverse=True))
for i, (a, b) in enumerate(zip("가나", "AB")):
    print(i, a, b)
```

> 💡 더 많은 내장 함수는 **부록 B** 에 정리해 두었어요.

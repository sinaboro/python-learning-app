# 04 | 컬렉션 자료형과 불리언

@goals

## 04.1 | 리스트

여러 값을 **순서대로** 한곳에 담는 자료형이에요. 대괄호 `[ ]` 안에 쉼표로 구분해 씁니다. 문자열처럼 인덱싱·슬라이싱이 되고, **값을 바꿀 수 있어요.**

```python
fruits = ["사과", "바나나", "포도"]
print(fruits[0], fruits[-1])
print(fruits[1:])
fruits[1] = "딸기"          # 값 바꾸기
print(fruits, len(fruits))
```

### 추가·삭제

| 메서드 | 하는 일 |
|---|---|
| append(x) | 맨 뒤에 x 추가 |
| insert(i, x) | i 번 자리에 x 넣기 |
| remove(x) | 값 x 를 찾아 지우기 (첫 번째 하나) |
| pop() / pop(i) | 맨 뒤(또는 i 번) 값을 꺼내며 지우기 |
| del 리스트[i] | i 번 지우기 |

```python
nums = [10, 20, 30]
nums.append(40)
nums.insert(0, 5)
print(nums)
nums.remove(20)
last = nums.pop()
print(nums, "꺼낸 값:", last)
```

### 정렬과 여러 기능

```python
scores = [70, 95, 82, 60]
scores.sort()                     # 오름차순으로 제자리 정렬
print(scores)
scores.sort(reverse=True)         # 내림차순
print(scores)
print(max(scores), min(scores), sum(scores))
print(sorted([3, 1, 2]))          # 원본은 두고 정렬된 새 리스트
print(82 in scores, scores.index(82))
```

> 💡 리스트 안에 리스트를 넣을 수도 있어요. `[[1, 2], [3, 4]]` 에서 `[1][0]` 은 3 이에요. 표 같은 데이터를 담을 때 씁니다.

## 04.2 | 튜플

튜플은 소괄호 `( )` 로 만드는 **바꿀 수 없는 리스트**예요. 한 번 정하면 바뀌면 안 되는 값(좌표, 생년월일 등)을 담을 때 써요.

```python
point = (3, 5)
print(point[0], point[1])
x, y = point                 # 튜플 풀기(언패킹)
print(f"x={x}, y={y}")
```

```python
point = (3, 5)
point[0] = 10                # 튜플은 바꿀 수 없다 → 오류
```

> 💡 값이 하나인 튜플은 `(5,)` 처럼 쉼표를 붙여야 해요. `(5)` 는 그냥 숫자 5 입니다.

## 04.3 | 딕셔너리

**키(key)와 값(value)을 짝지어** 저장하는 자료형이에요. 중괄호 `{ }` 안에 `키: 값` 을 씁니다. 사전에서 단어(키)로 뜻(값)을 찾는 것과 같아요.

```python
student = {"name": "김파이", "age": 20, "major": "컴퓨터"}
print(student["name"])
student["age"] = 21              # 값 바꾸기
student["email"] = "pi@ex.com"   # 새 키 추가
del student["major"]             # 삭제
print(student)
```

### 안전하게 꺼내기, 모두 돌아보기

```python
student = {"name": "김파이", "age": 20}
print(student.get("phone"))            # 없는 키 → None (오류 없음)
print(student.get("phone", "없음"))     # 없을 때 대신 쓸 값
print(student.keys())
print(student.values())
print(student.items())
print("name" in student)
```

!> `student["phone"]` 처럼 없는 키를 대괄호로 꺼내면 `KeyError` 가 나요. 있는지 모를 때는 `get()` 을 쓰세요.

## 04.4 | 집합

집합(set)은 **중복이 없고 순서도 없는** 자료형이에요. 중복 제거와 교집합·합집합 계산에 편리합니다.

```python
nums = [1, 2, 2, 3, 3, 3]
print(set(nums))                 # 중복이 사라진다
a = {"파이썬", "자바", "C"}
b = {"파이썬", "자바스크립트"}
print(a & b)                     # 교집합
print(len(a | b))                # 합집합의 크기
print(a - b)                     # 차집합
```

> 💡 집합은 순서가 없어서 출력 순서가 실행할 때마다 다를 수 있고, 인덱스(`[0]`)로 꺼낼 수 없어요.

## 04.5 | 불리언

**참(True)과 거짓(False)** 두 값만 있는 자료형이에요. 비교 결과가 불리언으로 나옵니다. (첫 글자는 대문자!)

```python
print(10 > 3)
print(10 == 3)
print(type(True))
```

### 참·거짓으로 취급되는 값

`bool()` 로 확인해 보면, **비어 있거나 0인 값은 거짓**, 나머지는 참이에요.

| 거짓(False)으로 취급 | 참(True)으로 취급 |
|---|---|
| 0, 0.0 | 0이 아닌 숫자 |
| "" (빈 문자열) | "a" |
| [], (), {} (빈 컬렉션) | [1], {"a": 1} |
| None | 그 밖의 대부분 |

```python
print(bool(0), bool(""), bool([]), bool(None))
print(bool(5), bool("hi"), bool([0]))
```

## 04.6 | 자료형 돌아보기

| 자료형 | 기호 | 순서 | 변경 | 중복 | 예 |
|---|---|---|---|---|---|
| 리스트 | [ ] | 있음 | 가능 | 가능 | [1, 2, 2] |
| 튜플 | ( ) | 있음 | 불가 | 가능 | (1, 2) |
| 딕셔너리 | {키: 값} | 있음* | 가능 | 키는 불가 | {"a": 1} |
| 집합 | { } | 없음 | 가능 | 불가 | {1, 2} |
| 문자열 | " " | 있음 | 불가 | 가능 | "abc" |

*파이썬 3.7부터 딕셔너리는 넣은 순서를 기억해요.

```python
# 상황에 맞는 자료형 고르기
shopping = ["우유", "빵", "우유"]          # 순서·중복 OK → 리스트
birthday = (2005, 3, 14)                  # 바뀌면 안 됨 → 튜플
phone_book = {"엄마": "010-1111-2222"}     # 이름으로 찾기 → 딕셔너리
visited = set(["서울", "부산", "서울"])     # 중복 없이 → 집합
print(shopping, birthday, phone_book, visited, sep="\n")
```

!> 빈 집합은 `set()` 으로 만들어요. `{}` 는 빈 **딕셔너리**입니다.

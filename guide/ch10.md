# 10 | 오류 읽고 예외 처리하기

@goals
- 오류 메시지(Traceback)를 읽고 원인을 찾을 수 있다.
- 자주 만나는 오류의 종류와 뜻을 안다.
- 필요한 예외만 골라 처리하고, as 로 오류 내용을 받을 수 있다.
- else 와 finally 의 실행 시점을 안다.
- raise 로 직접 예외를 일으키고, 오류에 강한 프로그램을 만든다.
@end

## 10.1 | 오류는 어떻게 읽고, 어떻게 처리해야 할까?

오류(에러)는 실패가 아니라 **컴퓨터가 알려 주는 힌트**예요. 오류 메시지를 읽는 법만 알면 대부분 스스로 고칠 수 있어요.

```python
prices = [1000, 2000, 3000]
print(prices[3])
```

### Traceback 읽는 순서

1. **맨 아래 줄부터** 읽어요. `IndexError: list index out of range` → 오류 종류와 이유
2. 그 위의 `line 2` → 몇 번째 줄에서 났는지
3. 그 줄의 코드를 보고 원인을 찾아요. (리스트는 0~2번까지인데 3번을 꺼냈어요)

### 자주 만나는 오류

| 오류 | 뜻 | 흔한 원인 |
|---|---|---|
| SyntaxError | 문법이 틀림 | 콜론·괄호·따옴표 빠짐 |
| IndentationError | 들여쓰기가 틀림 | 공백 개수가 다름 |
| NameError | 모르는 이름 | 오타, 변수를 만들기 전에 사용 |
| TypeError | 자료형이 맞지 않음 | "a" + 1 |
| ValueError | 값이 알맞지 않음 | int("abc") |
| IndexError | 없는 번호 | 리스트 범위를 넘음 |
| KeyError | 없는 키 | 딕셔너리에 없는 키 |
| ZeroDivisionError | 0으로 나눔 | 10 / 0 |
| FileNotFoundError | 파일이 없음 | 파일 이름·경로 오타 |

> 💡 **문법 오류**(SyntaxError)는 실행 전에 발견되어 아예 실행되지 않고, 나머지는 실행 중에 생기는 **예외(exception)**예요. 예외는 try~except 로 처리할 수 있어요.

## 10.2 | 필요한 예외만 골라 처리하기

`except:` 만 쓰면 모든 오류를 다 잡아 버려서, 진짜 원인을 숨길 수 있어요. **예상되는 오류만 이름을 적어** 처리하는 것이 좋습니다.

```python input=10|0
try:
    a = int(input("나눌 수: "))
    b = int(input("나누는 수: "))
    print("결과:", a / b)
except ValueError:
    print("숫자를 입력해 주세요.")
except ZeroDivisionError:
    print("0 으로 나눌 수 없어요.")
```

### 여러 오류를 한 번에, as 로 오류 내용 받기

```python
data = {"a": 1}
for key in ["a", "b"]:
    try:
        print(key, "→", 10 / (data[key] - 1))
    except (KeyError, ZeroDivisionError) as e:   # 괄호로 묶어 여러 개
        print(f"{key}: {type(e).__name__} 발생 ({e})")
```

!> `except Exception:` 처럼 모든 예외를 잡을 때는 최소한 오류 내용을 출력하거나 기록하세요. 아무것도 안 하고 넘기면(`pass`) 문제를 찾기 아주 어려워져요.

## 10.3 | else 와 finally 로 실행 흐름 나누기

| 블록 | 실행되는 때 |
|---|---|
| try | 먼저 시도 |
| except | try 에서 오류가 났을 때 |
| else | try 에서 오류가 **없었을 때** |
| finally | 오류가 있든 없든 **항상** 마지막에 |

```python
def divide(a, b):
    try:
        result = a / b
    except ZeroDivisionError:
        print("  → 0으로 나눌 수 없음")
    else:
        print("  → 성공:", result)
    finally:
        print("  → 계산 끝 (항상 실행)")

print("10 / 2"); divide(10, 2)
print("10 / 0"); divide(10, 0)
```

> 💡 finally 는 파일 닫기, 연결 끊기처럼 **무슨 일이 있어도 꼭 해야 하는 정리 작업**에 써요.

## 10.4 | raise 로 직접 예외 발생시키기

문법적으로는 문제없지만 **규칙에 맞지 않는 값**일 때, 직접 예외를 일으킬 수 있어요.

```python
def set_age(age):
    if age < 0:
        raise ValueError("나이는 0 이상이어야 합니다")   # 예외를 직접 발생
    print(f"나이를 {age}살로 설정했어요")

try:
    set_age(20)
    set_age(-5)
except ValueError as e:
    print("오류:", e)
```

### 나만의 예외 만들기

```python
class NotEnoughMoney(Exception):          # Exception 을 상속해서 만든다
    pass

def pay(balance, price):
    if price > balance:
        raise NotEnoughMoney(f"{price - balance:,}원이 부족해요")
    return balance - price

try:
    print(pay(10000, 3000))
    print(pay(10000, 15000))
except NotEnoughMoney as e:
    print("결제 실패:", e)
```

## 10.5 | 오류에 대비한 메모장 프로그램 만들기

9장의 메모장을 업그레이드해요. 메모 파일이 없을 때, 빈 메모를 쓸 때, 메모를 지울 때 생길 수 있는 오류를 모두 처리합니다.

```python input=2|1||1|장보기|1|운동하기|3|5|3|1|2|4
# memo_safe.py — 오류에 대비한 메모장
import os
FILE = "memo_safe.txt"
if os.path.exists(FILE):
    os.remove(FILE)                            # 실습을 위해 파일 없이 시작

def load():
    try:
        with open(FILE, encoding="utf-8") as f:
            return [line.strip() for line in f]
    except FileNotFoundError:                  # 처음 실행하면 파일이 없다
        return []

def save(memos):
    with open(FILE, "w", encoding="utf-8") as f:
        f.write("\n".join(memos) + ("\n" if memos else ""))

while True:
    menu = input("\n[1]쓰기 [2]목록 [3]삭제 [4]끝 > ")
    memos = load()
    if menu == "1":
        text = input("메모: ").strip()
        if not text:
            print("빈 메모는 저장하지 않아요.")
            continue
        memos.append(text); save(memos); print("저장!")
    elif menu == "2":
        if not memos:
            print("메모가 없어요.")
        for i, m in enumerate(memos, 1):
            print(f"{i}. {m}")
    elif menu == "3":
        try:
            n = int(input("지울 번호: "))
            removed = memos.pop(n - 1)         # 없는 번호면 IndexError
            save(memos); print(f"'{removed}' 삭제")
        except ValueError:
            print("번호는 숫자로 입력해 주세요.")
        except IndexError:
            print("그런 번호의 메모는 없어요.")
    elif menu == "4":
        print("종료합니다."); break
```

> 💡 실행 결과를 보면 파일이 없을 때(목록), 빈 메모, 없는 번호(5) 를 모두 프로그램이 멈추지 않고 처리했어요. **사용자는 언제나 예상 밖의 입력을 한다**고 생각하고 대비하는 것이 좋은 프로그램입니다.

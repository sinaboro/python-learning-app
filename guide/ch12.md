# 12 | 한 걸음 더 깊게 알아보는 파이썬

@goals

- 이터러블·이터레이터·제너레이터의 관계를 이해한다.

## 12.1 | 값을 복사한다는 것은 무엇일까?

파이썬의 변수는 값을 담은 상자라기보다, **값(객체)에 붙인 이름표**에 가까워요. `b = a` 는 값을 복사하는 게 아니라 **같은 값에 이름표를 하나 더 붙이는 것**입니다.

```python
a = [1, 2, 3]
b = a                    # 같은 리스트에 이름표 b 를 하나 더
b.append(4)
print("a:", a)           # a 도 바뀌었다!
print(a is b)            # is: 같은 객체인가?
```

### 바뀌는 값과 바뀌지 않는 값

정수·문자열·튜플은 **바꿀 수 없는(immutable)** 값이라, "바꾼다"는 건 사실 새 값에 이름표를 옮겨 붙이는 거예요. 그래서 위 같은 문제가 생기지 않아요. 리스트·딕셔너리·집합처럼 **바뀌는(mutable)** 값을 다룰 때만 주의하면 됩니다.

```python
x = 10
y = x
y = y + 1                # 새 값 11 에 y 를 붙인다
print(x, y)              # x 는 그대로
```

### 진짜 복사하기: 얕은 복사와 깊은 복사

```python
import copy
original = [1, [10, 20]]
shallow = original.copy()          # 얕은 복사 (= list(original), original[:])
deep = copy.deepcopy(original)     # 깊은 복사: 안쪽 리스트까지 새로

original[0] = 99                   # 바깥 값 변경
original[1].append(30)             # 안쪽 리스트 변경
print("원본:", original)
print("얕은:", shallow)            # 안쪽 리스트는 함께 바뀜!
print("깊은:", deep)               # 완전히 독립
```

| 방법 | 바깥 리스트 | 안쪽 리스트 |
|---|---|---|
| b = a | 공유 | 공유 |
| a.copy() / a[:] | 새로 만듦 | 공유 |
| copy.deepcopy(a) | 새로 만듦 | 새로 만듦 |

> 💡 리스트 안에 리스트(2차원)가 있으면 `deepcopy` 를 쓰세요. 숫자·문자열만 담긴 리스트라면 `copy()` 로 충분해요.

### 함수에 리스트를 넘길 때

```python
def add_item(cart, item):
    cart.append(item)            # 넘겨받은 리스트를 직접 바꾼다

my_cart = ["우유"]
add_item(my_cart, "빵")
print(my_cart)                   # 함수 밖의 리스트도 바뀐다
```

## 12.2 | 함수를 값처럼 다루기

파이썬에서는 **함수도 값**이에요. 변수에 담고, 리스트에 넣고, 다른 함수에 넘기고, 함수에서 돌려줄 수 있어요. (이런 함수를 **일급 객체**라고 불러요)

```python
def shout(text):
    return text.upper() + "!"

speak = shout                    # 괄호 없이 쓰면 함수 자체를 가리킨다
print(speak("hello"))
print(type(shout))
```

### 함수를 인수로 넘기기

```python
def apply(func, values):
    return [func(v) for v in values]

print(apply(abs, [-1, -2, 3]))
print(apply(str.upper, ["a", "b"]))
print(apply(lambda x: x * x, [1, 2, 3]))
```

```python
# 계산기: 기호와 함수를 딕셔너리에 담기
ops = {"+": lambda a, b: a + b, "-": lambda a, b: a - b,
       "*": lambda a, b: a * b, "/": lambda a, b: a / b}
for sym in ops:
    print(f"8 {sym} 2 = {ops[sym](8, 2)}")
```

### 함수를 돌려주는 함수 (클로저)

```python
def make_multiplier(n):
    def multiply(x):
        return x * n             # 바깥 함수의 n 을 기억한다
    return multiply

double = make_multiplier(2)
triple = make_multiplier(3)
print(double(10), triple(10))
```

### 데코레이터 맛보기

함수를 받아 기능을 덧붙인 새 함수를 돌려주는 함수를 **데코레이터**라고 해요. `@이름` 으로 붙입니다.

```python
def log(func):
    def wrapper(*args):
        print(f"[기록] {func.__name__}{args} 호출")
        return func(*args)
    return wrapper

@log                             # add = log(add) 와 같다
def add(a, b):
    return a + b

print(add(3, 4))
```

## 12.3 | 반복의 정체, 이터러블과 제너레이터

for 문으로 돌 수 있는 것(리스트, 문자열, range, 딕셔너리, 파일…)을 **이터러블(iterable)**이라고 해요. for 문은 사실 뒤에서 이런 일을 합니다.

1. `iter(이터러블)` 로 **이터레이터**(값을 하나씩 꺼내 주는 도구)를 만든다
2. `next(이터레이터)` 로 다음 값을 하나씩 꺼낸다
3. 더 꺼낼 게 없으면 `StopIteration` 이 나고, for 문이 끝난다

```python
nums = [10, 20, 30]
it = iter(nums)
print(next(it))
print(next(it))
print(next(it))
print(next(it, "끝"))       # 기본값을 주면 오류 대신 그 값을 돌려준다
```

### 제너레이터: 필요할 때 하나씩 만들어 내는 함수

함수 안에서 `return` 대신 **yield** 를 쓰면 제너레이터가 돼요. 값을 한 번에 다 만들지 않고, **요청할 때마다 하나씩** 만들어 메모리를 아낍니다.

```python
def countdown(n):
    while n > 0:
        yield n                  # 값을 하나 내주고 여기서 잠시 멈춘다
        n -= 1

gen = countdown(3)
print(next(gen))
for value in gen:                # 남은 값을 이어서 꺼낸다
    print(value)
```

```python
# 리스트 vs 제너레이터 표현식: 메모리 크기 비교
import sys
big_list = [n * n for n in range(100_000)]
big_gen = (n * n for n in range(100_000))      # 대괄호 대신 소괄호
print("리스트:", sys.getsizeof(big_list), "바이트")
print("제너레이터:", sys.getsizeof(big_gen), "바이트")
print("합계는 같다:", sum(big_gen) == sum(big_list))
```

> 💡 range() 도 값을 미리 다 만들지 않는 이터러블이에요. 그래서 `range(10**9)` 도 순식간에 만들어집니다. 큰 파일을 한 줄씩 읽는 것(9장)도 같은 원리예요.

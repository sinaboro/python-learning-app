## 01.1 | 컴퓨터에게 일을 시키는 방법, 프로그래밍

컴퓨터는 아주 빠르고 정확하지만, **스스로 생각하지는 못합니다.** 무엇을, 어떤 순서로 할지 하나하나 알려 줘야 해요. 이렇게 컴퓨터에게 내리는 명령의 목록을 **프로그램**이라 하고, 프로그램을 만드는 일을 **프로그래밍(코딩)**이라고 합니다.

라면 끓이기를 예로 들어 볼게요. 사람에게는 "라면 끓여 줘" 한마디면 되지만, 컴퓨터에게는 순서를 빠짐없이 알려 줘야 합니다.

1. 냄비에 물 550mL를 붓는다.
2. 물이 끓을 때까지 불을 켠다.
3. 면과 스프를 넣는다.
4. 4분 30초 기다린 뒤 불을 끈다.

이렇게 일을 처리하는 **순서와 방법**을 **알고리즘**이라고 해요. 프로그래밍은 알고리즘을 컴퓨터가 알아듣는 말, 즉 **프로그래밍 언어**로 옮겨 적는 일입니다.

```python
# 컴퓨터에게 내리는 첫 번째 명령: 화면에 글자를 보여 줘!
print("안녕하세요, 파이썬!")
```

> 💡 `print()` 는 괄호 안의 내용을 화면에 보여 주는 명령이에요. 앞으로 가장 많이 쓰게 될 친구입니다.

## 01.2 | 왜 파이썬을 공부해야 할까?

프로그래밍 언어는 C, Java, JavaScript 등 아주 많아요. 그중 파이썬(Python)은 처음 배우기에 특히 좋습니다.

- **문법이 쉽고 짧아요.** 영어 문장처럼 읽혀서 처음 보는 사람도 뜻을 짐작할 수 있어요.
- **쓰이는 곳이 넓어요.** 인공지능·데이터 분석, 웹 서비스, 업무 자동화, 게임까지 만들 수 있어요.
- **도구가 풍부해요.** 다른 사람이 만들어 둔 라이브러리를 가져다 쓰면 어려운 일도 몇 줄로 끝나요.
- **함께 배우는 사람이 많아요.** 모르는 것을 검색하면 답을 쉽게 찾을 수 있어요.

같은 일을 하는 코드를 다른 언어와 비교해 보면 파이썬이 얼마나 간단한지 알 수 있어요. 아래는 1부터 5까지 더하는 파이썬 코드입니다.

```python
total = 0
for n in range(1, 6):   # 1, 2, 3, 4, 5 를 차례로 꺼내서
    total = total + n   # 하나씩 더한다
print("1부터 5까지의 합:", total)
```

> 💡 지금은 코드를 다 이해하지 못해도 괜찮아요. "이렇게 짧게 쓸 수 있구나" 정도만 느끼면 충분합니다.

## 01.3 | 파이썬 실습을 위한 도구 준비하기

파이썬 코드를 실행하려면 두 가지가 필요해요.

| 도구 | 하는 일 | 비유 |
|---|---|---|
| 파이썬 (인터프리터) | 코드를 읽고 실행한다 | 요리사 |
| 코드 편집기 (VS Code) | 코드를 쓰고 저장한다 | 요리책을 쓰는 노트 |

### 파이썬 설치 (윈도우)

1. python.org 에 접속해 **Downloads** 에서 최신 버전(3.12 이상)을 내려받습니다.
2. 설치 첫 화면 아래의 **Add python.exe to PATH** 를 꼭 체크합니다.
3. **Install Now** 를 누릅니다.
4. 명령 프롬프트(cmd)를 열고 `python --version` 을 입력해 버전이 나오면 성공입니다.

```text
C:\> python --version
Python 3.12.0
```

!> **Add python.exe to PATH** 를 체크하지 않으면 명령 프롬프트에서 `python` 명령을 찾지 못해요. 놓쳤다면 설치 파일을 다시 실행해 **Modify** 로 고칠 수 있어요.

### VS Code 설치

1. code.visualstudio.com 에서 내려받아 설치합니다.
2. 왼쪽 **확장(Extensions)** 메뉴에서 **Python** 을 검색해 설치합니다. (Microsoft 제작)
3. 한국어 화면이 좋다면 **Korean Language Pack** 도 설치하세요.

> 💡 설치가 어렵다면 이 교안과 함께 제공되는 **학습 앱**에서 바로 코드를 실행해 볼 수 있어요. 처음 한 번만 인터넷이 필요합니다.

## 01.4 | 파이썬을 실행하는 다양한 방법 알아보기

파이썬 코드를 실행하는 방법은 크게 세 가지예요.

### ① 대화형 셸 (한 줄씩 바로 실행)

명령 프롬프트에서 `python` 을 입력하면 `>>>` 표시가 나와요. 여기에 코드를 한 줄 쓰고 Enter 를 누르면 바로 결과가 나옵니다. 계산기처럼 간단히 확인할 때 좋아요. 끝낼 때는 `exit()` 를 입력합니다.

```text
>>> 3 + 4
7
>>> print("반가워요")
반가워요
>>> exit()
```

### ② 파일로 저장해서 실행

VS Code 에서 `hello.py` 처럼 이름 끝이 **.py** 인 파일을 만들고 코드를 저장한 뒤, 오른쪽 위 **▷(실행)** 버튼을 누르거나 터미널에서 `python hello.py` 를 입력합니다. 여러 줄짜리 프로그램은 이렇게 만들어요.

```python
# hello.py — 파일로 저장해서 실행하는 첫 프로그램
print("첫 번째 줄")
print("두 번째 줄")
print("파일은 위에서 아래로 차례대로 실행돼요")
```

### ③ 노트북 (주피터·코랩)

코드를 **칸(셀)** 단위로 나눠 실행하고, 결과를 바로 아래에서 보는 방식이에요. 구글 코랩(colab.research.google.com)은 설치 없이 웹 브라우저에서 쓸 수 있어 데이터 분석·인공지능 공부에 많이 쓰입니다.

| 방법 | 장점 | 쓰기 좋은 때 |
|---|---|---|
| 대화형 셸 | 바로 결과 확인 | 짧은 계산, 기능 시험 |
| 파일 실행 | 저장·재사용 | 프로그램 만들기 |
| 노트북 | 칸마다 결과 확인 | 데이터 분석, 수업 실습 |

## 01.5 | 파이썬 실행하기 전 알아둬야 할 3가지

### ① 위에서 아래로, 한 줄씩

파이썬은 코드를 **맨 위부터 한 줄씩** 순서대로 실행해요. 순서를 바꾸면 결과도 바뀝니다.

```python
print("1. 일어난다")
print("2. 세수한다")
print("3. 학교에 간다")
```

### ② 대소문자와 기호를 정확히

`print` 를 `Print` 로 쓰면 다른 이름이 되어 오류가 나요. 따옴표와 괄호도 짝을 맞춰야 합니다. 기호는 반드시 **영어 자판(반각)** 으로 입력하세요.

```python
Print("안녕")    # P 를 대문자로 쓰면?
```

> 💡 오류 메시지의 마지막 줄을 읽어 보세요. `NameError: name 'Print' is not defined` 는 "Print 라는 이름을 모른다"는 뜻이에요. 오류는 실패가 아니라 **컴퓨터가 주는 힌트**입니다.

### ③ # 뒤는 주석 (사람을 위한 메모)

`#` 뒤에 쓴 글은 실행되지 않아요. 코드가 하는 일을 설명할 때 씁니다. 나중의 나와 동료를 위해 주석을 다는 습관을 들이세요.

```python
# 이 줄은 실행되지 않아요
print("주석 다음 줄은 실행돼요")   # 줄 끝에 쓴 주석도 무시돼요
```

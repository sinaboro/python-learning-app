## 09.1 | 출력이란 무엇일까?

**출력**은 프로그램이 결과를 바깥으로 내보내는 것이에요. 화면에 보여 주기(`print`), 파일에 저장하기, 인터넷으로 보내기 모두 출력입니다. 2장에서 배운 print 기능을 정리하고, 표처럼 줄 맞춰 출력하는 법을 더 배워 봐요.

```python
name, score = "김파이", 92.456
print("이름:", name, "점수:", score)            # 쉼표: 띄어쓰기로 연결
print("이름: " + name)                           # +: 문자열끼리만
print(f"이름: {name}, 점수: {score:.1f}")         # f-문자열 (가장 추천)
print("이름: {}, 점수: {:.1f}".format(name, score))  # format() 메서드
```

### 자릿수 맞추기

| 형식 | 뜻 | 예 | 결과 |
|---|---|---|---|
| {x:10} | 10칸 (글자는 왼쪽 정렬) | f"[{'abc':5}]" | [abc  ] |
| {x:>10} | 10칸 오른쪽 정렬 | f"[{'abc':>5}]" | [  abc] |
| {x:^10} | 10칸 가운데 정렬 | f"[{'abc':^5}]" | [ abc ] |
| {x:.2f} | 소수점 둘째 자리 | f"{3.14159:.2f}" | 3.14 |
| {x:,} | 천 단위 쉼표 | f"{1234567:,}" | 1,234,567 |
| {x:05} | 빈자리를 0으로 | f"{42:05}" | 00042 |

```python
items = [("커피", 4500), ("샌드위치", 7800), ("쿠키", 2000)]
print(f"{'메뉴':^8}|{'가격':>8}")
print("-" * 18)
for menu, price in items:
    print(f"{menu:<8}|{price:>8,}")
```

## 09.2 | 파일 출력 이해하기

프로그램이 끝나면 변수의 값은 사라져요. 오래 남기려면 **파일**에 저장해야 합니다. `open(파일이름, 모드)` 로 파일을 열고, 다 쓰면 닫아요.

| 모드 | 뜻 | 파일이 없으면 | 파일이 있으면 |
|---|---|---|---|
| "w" | 쓰기 | 새로 만든다 | **내용을 지우고** 새로 쓴다 |
| "a" | 덧붙이기 | 새로 만든다 | 끝에 이어 쓴다 |
| "r" | 읽기 (기본값) | 오류 | 읽는다 |

```python
f = open("hello.txt", "w", encoding="utf-8")   # 한글은 encoding="utf-8" 을 꼭!
f.write("안녕하세요\n")                          # write 는 줄바꿈을 자동으로 넣지 않는다
f.write("파일에 저장된 두 번째 줄\n")
f.close()                                       # 다 쓰면 닫기
print("hello.txt 저장 완료")
```

### with 문: 자동으로 닫아 주는 안전한 방법

```python
with open("diary.txt", "w", encoding="utf-8") as f:
    f.write("11월 4일: 파이썬 파일 저장을 배웠다.\n")
with open("diary.txt", "a", encoding="utf-8") as f:   # a: 이어 쓰기
    f.write("11월 5일: 파일 읽기를 배울 예정.\n")
    print("print 로도 파일에 쓸 수 있다", file=f)
print("diary.txt 에 3줄 저장")
```

> 💡 with 블록이 끝나면 파일이 **자동으로 닫혀요.** close() 를 잊을 걱정이 없으니 항상 with 를 쓰는 습관을 들이세요.

## 09.3 | 입력이란 무엇일까?

**입력**은 바깥에서 프로그램으로 값을 받아들이는 것이에요. 키보드, 파일, 센서, 인터넷 모두 입력이 될 수 있어요. 가장 기본은 키보드로 입력받는 `input()` 입니다.

```python input=김파이
name = input("이름을 입력하세요: ")     # 안내 문구를 보여 주고 Enter 까지 기다린다
print(f"{name}님, 환영합니다!")
```

### input() 은 항상 문자열을 돌려줘요

```python input=20|30
a = input("첫 번째 숫자: ")
b = input("두 번째 숫자: ")
print("그냥 더하면:", a + b)              # 문자열끼리 붙어 버린다
print("숫자로 바꿔 더하면:", int(a) + int(b))
```

### 한 줄에 여러 값 입력받기

```python input=3 5 8
nums = input("숫자 여러 개 (띄어쓰기로): ").split()   # ['3', '5', '8']
nums = [int(n) for n in nums]                       # 모두 정수로
print("합계:", sum(nums), "평균:", sum(nums) / len(nums))
```

> 💡 `map(int, input().split())` 처럼 써도 같은 결과예요. 코딩 테스트에서 자주 보는 형태입니다.

## 09.4 | 파일 입력 이해하기

앞에서 저장한 `diary.txt` 를 읽어 봐요.

```python
with open("diary.txt", "r", encoding="utf-8") as f:
    content = f.read()                    # 전체를 문자열 하나로
print(content)
```

| 메서드 | 돌려주는 값 |
|---|---|
| read() | 파일 전체를 문자열 하나로 |
| readline() | 한 줄만 (부를 때마다 다음 줄) |
| readlines() | 모든 줄을 리스트로 ['첫 줄\n', '둘째 줄\n'] |

```python
with open("diary.txt", encoding="utf-8") as f:   # 모드를 생략하면 "r"
    lines = f.readlines()
print(len(lines), "줄")
print(lines[0].strip())                          # strip() 으로 줄 끝의 \n 제거
```

!> 없는 파일을 "r" 로 열면 `FileNotFoundError` 가 나요. 파일 이름과 위치(폴더)를 확인하세요. 10장에서 이 오류를 처리하는 법을 배워요.

## 09.5 | 파일을 한 줄씩 읽어 처리하기

파일 객체는 for 문으로 돌면 **한 줄씩** 꺼내 줘요. 큰 파일도 메모리를 적게 쓰며 처리할 수 있어요.

```python
# 성적 파일 만들기 (이름,점수)
with open("scores.csv", "w", encoding="utf-8") as f:
    f.write("김파이,88\n이코딩,95\n박자바,72\n최루비,64\n")

total, count = 0, 0
with open("scores.csv", encoding="utf-8") as f:
    for line in f:                          # 한 줄씩
        name, score = line.strip().split(",")
        score = int(score)
        mark = "합격" if score >= 70 else "불합격"
        print(f"{name}: {score}점 {mark}")
        total += score; count += 1
print(f"평균 {total / count:.1f}점")
```

```python
# 합격자만 골라 새 파일에 저장하기
with open("scores.csv", encoding="utf-8") as src, \
     open("passed.txt", "w", encoding="utf-8") as dst:
    for line in src:
        name, score = line.strip().split(",")
        if int(score) >= 70:
            dst.write(name + "\n")
print(open("passed.txt", encoding="utf-8").read())
```

## 09.6 | 메모장 프로그램 만들어보기

지금까지 배운 입력·출력·파일·반복·조건을 모아 **메모장 프로그램**을 만들어 봐요. 메모를 쓰면 `memo.txt` 에 저장되고, 목록 보기로 저장된 메모를 볼 수 있어요.

```python input=1|우유 사기|1|파이썬 복습|2|3
# memo.py — 메모장 프로그램 (1: 쓰기, 2: 목록, 3: 끝)
FILE = "memo.txt"
open(FILE, "w", encoding="utf-8").close()     # 실습을 위해 빈 파일로 시작

while True:
    menu = input("\n[1] 메모 쓰기 [2] 목록 보기 [3] 끝내기 > ")
    if menu == "1":
        text = input("메모 내용: ")
        with open(FILE, "a", encoding="utf-8") as f:
            f.write(text + "\n")
        print("저장했어요.")
    elif menu == "2":
        with open(FILE, encoding="utf-8") as f:
            for i, line in enumerate(f, start=1):
                print(f"{i}. {line.strip()}")
    elif menu == "3":
        print("메모장을 종료합니다.")
        break
    else:
        print("1, 2, 3 중에서 골라 주세요.")
```

> 💡 이 프로그램은 메모 파일이 없거나 이상한 입력이 들어오면 문제가 생길 수 있어요. 10장에서 **오류에 대비한 메모장**으로 업그레이드합니다.

## 08.1 | 클래스와 인스턴스

게임 속 캐릭터를 생각해 보세요. 캐릭터마다 이름·체력(**데이터**)이 있고, 공격하기·회복하기(**기능**)를 할 수 있어요. **클래스**는 이렇게 데이터와 기능을 하나로 묶은 **설계도**이고, 설계도로 만든 실제 물건을 **인스턴스(객체)**라고 합니다.

| 비유 | 클래스 | 인스턴스 |
|---|---|---|
| 붕어빵 | 붕어빵 틀 | 하나하나의 붕어빵 |
| 게임 | 캐릭터 설계 | 전사 "아서", 마법사 "멀린" |

```python
class Character:                     # 클래스 이름은 대문자로 시작 (PascalCase)
    def __init__(self, name, hp):    # 인스턴스를 만들 때 자동으로 실행
        self.name = name             # self.이름 = 인스턴스마다 따로 가지는 값(속성)
        self.hp = hp

    def attack(self, target):        # 메서드: 클래스 안의 함수
        print(f"{self.name}이(가) {target.name}을(를) 공격!")
        target.hp -= 10

hero = Character("아서", 100)         # 인스턴스 만들기
monster = Character("슬라임", 30)
hero.attack(monster)
print(monster.name, "남은 체력:", monster.hp)
```

> 💡 **self** 는 "지금 이 인스턴스 자신"을 가리켜요. 메서드의 첫 매개변수로 꼭 쓰고, 부를 때는 `hero.attack(monster)` 처럼 self 자리를 비워 둡니다. 파이썬이 알아서 hero 를 넣어 줘요.

### 인스턴스는 서로 독립적이에요

```python
class Counter:
    def __init__(self):
        self.value = 0
    def up(self):
        self.value += 1

a = Counter(); b = Counter()
a.up(); a.up(); b.up()
print(a.value, b.value)
```

## 08.2 | 상속과 다형성

**상속**은 이미 있는 클래스(부모)의 속성과 메서드를 그대로 물려받아 새 클래스(자식)를 만드는 것이에요. 공통 부분은 부모에, 다른 부분만 자식에 쓰면 됩니다.

```python
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        print(f"{self.name}: ...")

class Dog(Animal):                   # Animal 을 물려받는다
    def speak(self):                 # 같은 이름으로 다시 정의 (오버라이딩)
        print(f"{self.name}: 멍멍!")

class Cat(Animal):
    def speak(self):
        print(f"{self.name}: 야옹~")

for pet in [Dog("바둑이"), Cat("나비"), Animal("거북이")]:
    pet.speak()                      # 같은 명령, 다른 동작 → 다형성
```

**다형성**은 같은 이름의 메서드를 불러도 객체의 종류에 따라 다르게 동작하는 것이에요. 위에서 `speak()` 하나로 개·고양이가 각자 다르게 울죠.

### super(): 부모의 기능을 이어서 쓰기

```python
class Student:
    def __init__(self, name):
        self.name = name

class Graduate(Student):
    def __init__(self, name, thesis):
        super().__init__(name)       # 부모의 __init__ 으로 name 설정
        self.thesis = thesis         # 자식만의 속성 추가

g = Graduate("김파이", "AI 연구")
print(g.name, "/", g.thesis)
print(isinstance(g, Student))        # 자식은 부모의 한 종류
```

## 08.3 | 클래스 변수와 메서드

| 구분 | 만드는 곳 | 공유 | 예 |
|---|---|---|---|
| 인스턴스 변수 | __init__ 안 self.이름 | 인스턴스마다 따로 | self.name |
| 클래스 변수 | 클래스 바로 아래 | 모든 인스턴스가 공유 | count = 0 |

```python
class Member:
    count = 0                        # 클래스 변수: 모든 회원이 함께 쓰는 값

    def __init__(self, name):
        self.name = name             # 인스턴스 변수
        Member.count += 1            # 회원이 생길 때마다 1 증가

Member("김파이"); Member("이코딩"); m = Member("박자바")
print("전체 회원 수:", Member.count, "/", m.count)
```

### 메서드의 종류

```python
class MathTool:
    pi = 3.14159

    def __init__(self, r):
        self.r = r
    def area(self):                  # 인스턴스 메서드: self 사용
        return MathTool.pi * self.r ** 2

    @classmethod
    def info(cls):                   # 클래스 메서드: 클래스(cls) 사용
        return f"원주율 {cls.pi}"

    @staticmethod
    def add(a, b):                   # 정적 메서드: self·cls 없이 독립적인 기능
        return a + b

print(round(MathTool(2).area(), 2), MathTool.info(), MathTool.add(3, 4))
```

### __str__: print 했을 때 보기 좋게

```python
class Book:
    def __init__(self, title, price):
        self.title, self.price = title, price
    def __str__(self):
        return f"『{self.title}』 {self.price:,}원"

print(Book("파이썬 첫걸음", 18000))
```

## 08.4 | 클래스 연습하기

은행 계좌 클래스를 만들어 봐요. 입금·출금 기능과, 잔액이 부족할 때의 처리까지 넣습니다.

```python
class BankAccount:
    bank = "파이은행"                    # 클래스 변수

    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        self.history = []                # 거래 기록

    def deposit(self, amount):
        self.balance += amount
        self.history.append(f"입금 {amount:,}")

    def withdraw(self, amount):
        if amount > self.balance:
            print(f"잔액 부족! (잔액 {self.balance:,}원)")
            return False
        self.balance -= amount
        self.history.append(f"출금 {amount:,}")
        return True

    def __str__(self):
        return f"[{self.bank}] {self.owner} 님 잔액 {self.balance:,}원"

acc = BankAccount("김파이", 10000)
acc.deposit(5000)
acc.withdraw(30000)
acc.withdraw(3000)
print(acc)
print(acc.history)
```

```python
# 상속으로 이자 기능이 있는 적금 계좌 만들기
class SavingAccount(BankAccount):
    def __init__(self, owner, balance=0, rate=0.03):
        super().__init__(owner, balance)
        self.rate = rate
    def add_interest(self):
        interest = int(self.balance * self.rate)
        self.deposit(interest)
        print(f"이자 {interest:,}원 지급")

s = SavingAccount("이코딩", 100000)
s.add_interest()
print(s)
```
